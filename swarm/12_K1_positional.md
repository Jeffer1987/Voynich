# 12 K1 positional: can verbose cipher + abbreviation also give T1 (line-final -m), T2 (paragraph-initial gallows), T3 (A/B)?

Script: `swarm/scripts/k1_positional.py` (python -I; args parsed_zl3b.json baselines_dir out.json; ~20 s). It exec's the unmodified head of `k1_sim.py` (same fingerprint, abbreviation, grids). Raw: scratchpad `k1_pos.txt/json`.
Base model = best K1 of note 10: Italian (Dante, 35k tokens), abbreviation pv .5 + short-word table, verbose 11x11 grid, seed 2 (dist 1.21; h2 2.10, wl 6.09, hapax .60). Lines/paragraphs: word-count structure resampled from real Voynich paragraphs (independent of text), 5 layout seeds. The same metric functions are run on Voynich (ZL3b, P-lines, 740 paragraphs) and on the simulation, so "last glyph" etc. are glyph units in both (EVA ch/sh/cXh as one glyph; sim glyphs = A/B grid cells).
Latin best config was run for M0 only (same conclusions). One plaintext, one codebook seed: no variance over codebooks (limitation).

## Verdicts
- **T1 line-final -m:** coarse rate: emerges partly for free only if the *plaintext's own verse endings* are used as lines (rhyme words; +16 points, same magnitude as Voynich +14), but that is a different mechanism with the wrong stem pattern and no length dependence, and it needs poetry laid out in verse lines. With reflowed prose lines nothing emerges. **Reproducible with one scribal rule, only if the rule is applied to cipher glyphs**: "last glyph of the line-final word, if in a 2-member set S, becomes M" (probability p, scaled with line length). It then reproduces the *specific* pattern (same-stem alternation 82% vs 50% attested, gradient confined to the last word, two sources into one target, rate rising with words/line 8->19% with the scale term) with 4-5 parameters (S, M, p0, length slope, optional eligibility fraction). Most of the "specificity" is built in by the rule's form (same stem, last word only); what is not fitted and nonetheless matches is stems attested .82/.53 vs .80/.50 and the split between sources. Misses: negative-shift concentration .84-.90 vs .65, mid-line leakage of M, overdispersion is under-dispersed unless eligibility is added. A natural *plaintext-level* line-end suspension does not work: in a verbose cipher it rewrites two glyphs, so the stem changes (attested 0%); it works only with a contrived codebook where the substituted letters share a grid row with the mark. Overall: "plausible scribal rule", but the rule must live at the glyph level, i.e. the scribe abbreviates/alters the ciphertext, not the plaintext. This sits oddly with K1 as "the cipher text is a real language".
- **T2 paragraph-initial gallows:** M0: nothing emerges (stanza/chapter starts +3 to +10 points at most, no marker class). M1b: one rule (prepend/replace a marker from a small rare set with a skewed distribution) reproduces 82-84% vs 25%, first word only, and costs nothing in h2/wl/hapax. It needs 4 fitted choices (q, marker set, 3 weights, and that markers are rare elsewhere, which Voynich shows: p 0.6% elsewhere). The "ornamental initial / rubricated capital" reading is historically plausible, but then the markers should not be ordinary letters (they are, with distinct paragraph-vs-mid distributions), so the rule is **reproducible with one plausible rule but with a free skewed distribution**; the explanatory content is zero beyond restating the data.
- **T3 A/B:** nothing emerges from topic or random page split (0 suffixes). A single "alternate spelling of the commonest ending symbol(s)" in the codebook gives ending-only differences with no h2/wl/hapax change, i.e. the right *kind* of difference (2 underlying endings, d 4-5 vs Voynich 2.5-3.6, d too large because the swap is deterministic). Swapping more symbols leaks into prefixes, abbreviation-intensity differences change word length, a new grid changes everything: so only the narrowly aimed variant works. **Reproducible with one rule that is chosen to hit the target; ad hoc in its aim** (which symbols are swapped is what A/B is). It is not an independent check: the Voynich result is just reproduced as "two code tables differing in the ending cells".

## Parameters and overfitting
Base model ~7 (language, pv, short table, grid, seed; tuned to 4 fingerprint features). Added: T1 about 5, T2 about 6, T3 about 2-3: roughly 13-14 extra against 7-9 matched numbers (T1 rate, T1 by-n trend, T1 stem pairing, T2 rate, T2 rarity elsewhere, T2 word-2, T3 d for 2-3 endings, h2/wl unchanged). Several matches are by construction (same stem, last word only, first word only, h2 unchanged under a cell swap). The genuinely unfitted checks are few (stem attestation rates, source split, no side effect on fingerprint) and the rules also leave hapax at .60-.63, so the K1 hapax miss (Voynich .71) is untouched. Stated honestly: K1 plus three position-conditioned scribal rules can be made to look like the data; it was not predicted by K1, and every rule is a restatement of the observation. One plaintext, one seed, ad hoc tolerances, ZL transcription only.

## What would discriminate "scribal convention on a cipher" from "generator"
1. Physical vs logical line end: the cipher+scribe model ties the -m rule to the writing surface (margin, wrap around drawings); note 08 already found it on short non-margin paragraph-final lines (9%) and weakly on fill, which favours a line-structured process. Test -m, y/d-initial and gallows rates on lines whose length is dictated by a drawing vs free lines, and on the line that the writing continues across a gap.
2. Plaintext dependence of the rule: under K1 the propensity is a property of the word type (lexical, stable over the manuscript); under a generator with line state it varies with line/page. Measure per-type consistency across distant pages versus within-page clustering (note 08: overdispersion at stem level and page level both present).
3. Does the rule leave the word-level syntax intact? A cipher on real language retains word-to-word dependence across the line break; compare line-final word -> next line-initial word mutual information with within-line neighbours (a generator with an independent edge state predicts a break).
4. Calibration: run the same T1/T2 metrics on a copy-and-modify self-citation generator laid out in lines; if the edge pattern needs the same hand-coded rule there, the two accounts tie on parsimony, and only 1-3 can separate them.
5. Medieval abbreviation: an actually medieval Latin herbal text (not Dante/Caesar) under real suspension rules would test whether line-final marks of that kind ever substitute within the same stem in a 1:1 manner.
